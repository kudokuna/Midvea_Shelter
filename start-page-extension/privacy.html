Редакция от 15 августа 2026 года

Midvea Shelter — расширение новой вкладки, спроектированное по принципу local-first. Мы не продаём пользовательские данные и не используем скрытую аналитику.

Какие данные используются

  • закладки Chrome — для отображения и управления выбранными пользователем закладками и папками;
  • локальное хранилище Chrome — для настроек, заметок, выбранного оформления и кэша;
  • геолокация — только после разрешения пользователя, чтобы запросить погоду;
  • сетевые запросы — к выбранному поисковику, источникам обоев, подсказкам и погодному сервису Open-Meteo.

Передача и хранение

Настройки и заметки сохраняются средствами Chrome на устройстве пользователя. При обращении к внешнему сервису ему передаются только данные, необходимые для выбранной функции, например координаты для погоды или поисковая фраза.

Управление данными

Пользователь может изменить или удалить закладки, заметки и настройки через интерфейс расширения либо удалить расширение и его локальные данные средствами Chrome.

Контакты

Перед публикацией в Chrome Web Store здесь будет указан актуальный адрес поддержки разработчика.
