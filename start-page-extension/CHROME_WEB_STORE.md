# Chrome Web Store — релиз 1.1

## Назначение

Midvea Shelter заменяет новую вкладку на персональное рабочее пространство с закладками Chrome, погодой, заметками, Pomodoro, звуковым фоном и сменными обоями.

## Краткое описание

- English: A calm, local-first new tab with bookmarks, weather, notes, focus tools, and backgrounds.
- Русский: Спокойная локальная новая вкладка с закладками, погодой, заметками, фокус-инструментами и фонами.
- Українська: Спокійна локальна нова вкладка із закладками, погодою, нотатками, фокус-інструментами та фонами.

## Обоснование разрешений

- `storage` — настройки, заметки, кэш погоды и состояние виджетов.
- `unlimitedStorage` — загруженные пользователем изображения и видео могут превышать стандартную квоту локального хранилища.
- `geolocation` — определение города для погоды только после системного согласия пользователя.
- `bookmarks` — показ, создание, редактирование, импорт и экспорт закладок по действиям пользователя.
- `alarms` — завершение Pomodoro при закрытой новой вкладке.
- `notifications` — необязательное системное уведомление о завершении Pomodoro.
- Host permissions — запросы только к явно используемым Reddit, DuckDuckGo, Bing, Open-Meteo и Google Suggestions.

## Privacy practices

- Single purpose: персональная новая вкладка и инструменты концентрации.
- Закладки, заметки, настройки, геолокация и пользовательский контент используются только для функций расширения.
- Данные не продаются, не используются для рекламы или кредитных решений и не передаются вне запросов, необходимых выбранной функции.
- В кабинете отметить локальную обработку location, web history/bookmarks и user-generated content, если эти поля предлагаются формой.

## Перед отправкой

1. Запустить `./build-store-package.ps1` и загрузить ZIP из `dist`.
2. Загрузить скриншоты 1280×800 или 640×400 и промо-изображения.
3. Указать публичный HTTPS URL политики конфиденциальности и актуальный адрес поддержки.
4. Заполнить Store Listing на английском, русском и украинском; выбрать Productivity.
5. Проверить распакованную сборку через `chrome://extensions`, затем отправить на review.

## Проверка обновления 1.0 → 1.1

1. Установить опубликованную 1.0 и создать закладки, заметки, собственные иконки и обои.
2. Обновить её распакованной сборкой 1.1 с тем же extension ID.
3. Убедиться, что настройки и пользовательские данные сохранились, а `midveaDataSchemaVersion` равен `1`.
4. Экспортировать полную JSON-копию, изменить данные и выполнить восстановление.
5. Проверить восстановление дерева закладок, активной и стартовой категорий и собственных иконок.
